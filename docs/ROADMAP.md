# 开发路线图

本文档记录 Qiniu Browser 的开发进度和未来规划。

---

## ✅ Phase 1: 核心功能 (已完成)

**时间**: 2024-2026

### 基础架构
- [x] Tauri 2.0 + React 18 项目搭建
- [x] Tailwind CSS 4 + Shadcn UI 集成
- [x] 主题系统（亮色/暗色模式）
- [x] 响应式布局设计

### 认证与安全
- [x] 七牛云 Qbox Token 签名实现
- [x] 本地凭证安全存储
- [x] 从 Kodo Browser 导入历史凭证
- [x] 多账号管理

### 空间管理
- [x] 查看存储空间列表
- [x] 创建存储空间
- [x] 删除存储空间
- [x] 空间详情查看

### 文件管理
- [x] 文件列表展示
- [x] 文件上传（单个/批量）
- [x] 文件下载
- [x] 文件删除（单个/批量）
- [x] 文件重命名
- [x] 文件夹导航
- [x] 目录缓存优化

### 外链管理
- [x] 自动获取绑定域名
- [x] 一键复制文件外链
- [x] 外链状态反馈

### CDN 功能
- [x] URL 刷新
- [x] 目录刷新

### 用户体验
- [x] 可调节侧边栏宽度
- [x] 文件类型图标识别
- [x] 文件大小智能格式化
- [x] 时间格式化显示
- [x] 加载状态提示
- [x] 错误提示优化

## ✅ Phase 2: 功能增强 (已完成)

### 文件操作增强
- [x] 文件拖拽上传
- [x] 上传进度显示
- [x] 文件搜索功能（Ctrl+F 快捷键）
- [x] 文件重命名（内联编辑）
- [x] 文件夹创建
- [x] 文件夹下载（递归下载所有文件）

### 性能优化
- [x] 大文件列表分页加载（自动加载更多）
- [x] 虚拟滚动优化（使用 @tanstack/react-virtual）
- [x] 请求并发控制
- [x] 目录缓存（带过期时间）

### 批量操作
- [x] 批量选择文件（复选框 + 全选）
- [x] 批量下载
- [x] 批量删除
- [x] 批量导出外链

### 用户体验增强
- [x] 传输面板（实时显示上传/下载进度）
- [x] 浏览器前进/后退支持（鼠标侧键）
- [x] 键盘快捷键（PgUp/PgDn/Home/End）
- [x] 文件排序（按名称/大小/时间）
- [x] 搜索结果高亮
- [x] 面包屑导航
