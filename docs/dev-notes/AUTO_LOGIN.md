# 自动登录功能说明

## 功能概述

为了提升用户体验，Qiniu Browser 现在支持自动登录功能，刷新页面（F5）后无需重新输入凭证。

## 功能特性

### 1. 记住上次登录的账号
- 每次成功登录后，系统会自动记住当前登录的账号
- 使用 `localStorage` 存储上次登录的 AccessKey

### 2. 自动登录开关
- **账号列表页面**：顶部显示"自动登录上次使用的账号"开关
- **新建账号页面**：表单中显示"下次自动登录"选项
- 用户可以随时开启或关闭自动登录功能

### 3. 自动登录流程
1. 页面加载时检查是否启用了自动登录
2. 如果启用，查找上次登录的账号
3. 自动使用该账号的凭证进行登录
4. 如果自动登录失败，显示错误提示并返回登录界面

## 使用方法

### 方式一：从账号列表启用
1. 打开应用，进入账号列表页面
2. 勾选顶部的"自动登录上次使用的账号"
3. 选择任意账号登录
4. 下次刷新页面时会自动登录该账号

### 方式二：从登录表单启用
1. 点击"添加新账号"
2. 输入 AK/SK 和描述
3. 勾选"记住凭证"和"下次自动登录"
4. 点击登录
5. 下次刷新页面时会自动登录

## 安全说明

### 数据存储位置
- **凭证数据**：存储在 Tauri 的安全存储中（由 Rust 后端管理）
- **自动登录配置**：存储在浏览器的 `localStorage` 中
- **上次登录账号**：仅存储 AccessKey（不存储 SecretKey）

### 安全建议
1. **公共设备**：不建议在公共电脑上启用自动登录
2. **个人设备**：可以安全地启用自动登录，提升使用体验
3. **多账号切换**：切换账号后，自动登录会记住新账号

## 技术实现

### 存储键名
```typescript
// localStorage 键名
'qiniu_auto_login'      // 是否启用自动登录 (true/false)
'qiniu_last_login_ak'   // 上次登录的 AccessKey
```

### 自动登录逻辑
```typescript
// 1. 检查是否启用自动登录
const autoLogin = localStorage.getItem('qiniu_auto_login') === 'true';

// 2. 获取上次登录的账号
const lastLoginKey = localStorage.getItem('qiniu_last_login_ak');

// 3. 从历史记录中查找完整凭证
const lastAccount = historyItems.find(item => item.accessKey === lastLoginKey);

// 4. 自动登录
if (lastAccount && autoLogin) {
  await doLogin(lastAccount.accessKey, lastAccount.accessSecret);
}
```

## 用户体验优化

### 优化点
1. ✅ **无感刷新**：刷新页面后自动登录，无需重新输入
2. ✅ **灵活控制**：用户可以随时开启/关闭自动登录
3. ✅ **失败提示**：自动登录失败时显示友好的错误提示
4. ✅ **多账号支持**：自动记住最后使用的账号

### 交互流程
```
页面加载
  ↓
检查自动登录开关
  ↓
已启用？
  ├─ 是 → 查找上次账号 → 自动登录 → 成功进入应用
  │                              ↓
  │                            失败 → 显示错误 → 返回登录页
  └─ 否 → 显示登录页
```

## 常见问题

### Q: 自动登录失败怎么办？
A: 可能的原因：
- 凭证已过期或被删除
- 网络连接问题
- 七牛云 API 异常

解决方法：系统会自动返回登录页面，手动选择账号重新登录即可。

### Q: 如何关闭自动登录？
A: 
- 方式一：在账号列表页面取消勾选"自动登录上次使用的账号"
- 方式二：在登录表单取消勾选"下次自动登录"

### Q: 切换账号后会自动登录哪个？
A: 系统会记住最后一次成功登录的账号，下次自动登录该账号。

### Q: 自动登录安全吗？
A: 
- 凭证存储在本地设备的安全存储中
- 仅在本地设备有效
- 建议仅在个人设备上启用
