# CDN 功能分析与开发建议

基于七牛云 CDN API 文档分析，以下是可以开发的功能模块。

## 当前已实现功能

✅ **缓存刷新** - 已实现刷新 URL 和目录
✅ **资源预取** - 已实现预取 URL

## 可开发的新功能

### 1. 域名管理模块 ⭐⭐⭐⭐⭐

**优先级：高** - 这是 CDN 管理的核心功能

#### 功能列表：
- **域名列表查看** - 显示所有 CDN 加速域名及其状态
- **域名详情查看** - 查看单个域名的详细配置
- **域名上下线** - 快速启用/停用域名加速服务
- **域名创建** - 添加新的 CDN 加速域名（普通域名/泛域名）
- **域名删除** - 注销不再使用的域名

#### API 接口：
```
GET  /domain              - 获取域名列表
GET  /domain/<Name>       - 获取域名信息
POST /domain/<Name>       - 创建域名
POST /domain/<Name>/online  - 上线域名
POST /domain/<Name>/offline - 下线域名
DELETE /domain/<Name>     - 删除域名
```

#### UI 设计建议：
- 域名列表页：表格展示，包含域名、状态、CNAME、创建时间等
- 状态标签：在线（绿色）、离线（灰色）、配置中（黄色）
- 快捷操作：上下线切换按钮、查看详情、删除
- 搜索过滤：按域名、状态筛选

---

### 2. 域名配置模块 ⭐⭐⭐⭐

**优先级：中高** - 提供精细化的域名配置管理

#### 功能列表：
- **源站配置** - 修改回源地址、协议、端口
- **缓存规则配置** - 设置不同文件类型的缓存时长
- **HTTPS 配置** - 开启 HTTPS、更换证书
- **防盗链配置** - Referer 防盗链、时间戳防盗链
- **访问控制** - IP 黑白名单、UA 黑白名单
- **响应头配置** - 自定义 HTTP 响应头
- **回源鉴权** - 配置回源时的身份验证

#### API 接口：
```
PUT /domain/<Name>/source      - 修改源站配置
PUT /domain/<Name>/cache       - 修改缓存规则
PUT /domain/<Name>/sslize      - 升级 HTTPS
PUT /domain/<Name>/httpsconf   - 修改证书
PUT /domain/<Name>/referer     - 配置 Referer 防盗链
PUT /domain/<Name>/timeacl     - 配置时间戳防盗链
PUT /domain/<Name>/ipacl       - 配置 IP 黑白名单
PUT /domain/<Name>/uaacl       - 配置 UA 黑白名单
PUT /domain/<Name>/respheader  - 修改响应头
PUT /domain/<Name>/bsauth      - 配置回源鉴权
```

#### UI 设计建议：
- 配置页面：分标签页展示不同配置模块
- 表单验证：实时校验配置参数的合法性
- 配置预览：修改前显示当前配置，修改后显示新配置对比
- 批量操作：支持多个域名批量应用相同配置

---

### 3. 用量统计模块 ⭐⭐⭐⭐

**优先级：中高** - 帮助用户了解 CDN 使用情况和费用

#### 功能列表：
- **流量统计** - 查看指定时间段的流量消耗
- **带宽统计** - 查看峰值带宽和平均带宽
- **请求数统计** - 查看 HTTP/HTTPS 请求次数
- **按域名统计** - 分域名查看用量数据
- **时间维度** - 支持按小时/天/月查询

#### API 接口：
```
GET /v2/tune/flux       - 流量查询
GET /v2/tune/bandwidth  - 带宽查询
GET /v2/tune/count      - 请求数查询
```

#### UI 设计建议：
- 图表展示：使用折线图/柱状图展示趋势
- 时间选择器：快捷选择今天/昨天/最近7天/最近30天
- 数据导出：支持导出 CSV/Excel
- 实时刷新：可选自动刷新数据

---

### 4. 运营统计模块 ⭐⭐⭐

**优先级：中** - 提供更深入的数据分析

#### 功能列表：
- **命中率统计** - CDN 缓存命中率分析
- **状态码分布** - HTTP 状态码统计（2xx/3xx/4xx/5xx）
- **TOP URL 统计** - 访问量最高的 URL 排行
- **TOP IP 统计** - 访问量最高的 IP 排行
- **独立 IP 统计** - UV（独立访客）统计
- **地区运营商分布** - 按地区和运营商分析流量

#### API 接口：
```
GET /v2/tune/hitrate    - 命中率查询
GET /v2/tune/statuscode - 状态码查询
GET /v2/tune/topurl     - TOP URL 查询
GET /v2/tune/topip      - TOP IP 查询
GET /v2/tune/uv         - 独立 IP 查询
GET /v2/tune/region     - 地区运营商分布
```

#### UI 设计建议：
- 饼图展示：状态码分布、地区分布
- 排行榜：TOP URL/IP 列表
- 趋势图：命中率、UV 变化趋势
- 数据对比：支持多个域名对比分析

---

### 5. 证书管理模块 ⭐⭐⭐

**优先级：中** - HTTPS 证书管理

#### 功能列表：
- **证书列表** - 查看所有上传的 SSL 证书
- **证书上传** - 上传新的 SSL 证书
- **证书详情** - 查看证书信息（域名、有效期、颁发者）
- **证书删除** - 删除不再使用的证书
- **证书到期提醒** - 证书即将过期时提醒用户

#### API 接口：
```
GET    /sslcert        - 获取证书列表
POST   /sslcert        - 上传证书
GET    /sslcert/<CertID> - 获取证书详情
DELETE /sslcert/<CertID> - 删除证书
```

#### UI 设计建议：
- 证书卡片：显示证书名称、绑定域名、有效期
- 状态标识：正常（绿色）、即将过期（黄色）、已过期（红色）
- 快捷操作：查看详情、绑定域名、删除
- 证书上传：支持拖拽上传证书文件

---

### 6. 日志下载模块 ⭐⭐

**优先级：低** - 高级用户需求

#### 功能列表：
- **日志列表查询** - 查看指定日期的日志文件列表
- **日志下载** - 下载 CDN 访问日志
- **批量下载** - 支持批量下载多个日志文件

#### API 接口：
```
GET /v2/tune/log/list - 获取日志列表
```

#### UI 设计建议：
- 日期选择：选择要下载的日志日期
- 日志列表：显示日志文件名、大小、下载链接
- 批量操作：支持勾选多个日志文件批量下载

## 开发优先级建议

### 第一阶段（核心功能）
1. **域名管理** - 域名列表、查看详情、上下线

3. **域名配置** - 源站配置、缓存规则、HTTPS 配置

### 第三阶段（数据分析）
5. **运营统计** - 命中率、状态码、TOP 统计
6. **证书管理** - 证书列表、上传、到期提醒

### 第四阶段（高级功能）
7. **日志下载** - 日志查询和下载
8. **批量操作** - 批量配置、批量刷新等

## 技术实现要点

### 鉴权方式
- **Qiniu 签名** - 用于域名管理、域名配置（`api.qiniu.com`）
- **QBox 签名** - 用于统计、缓存、证书、日志（`fusion.qiniuapi.com`）

### API 限流
- 域名管理/配置：QPS 10
- 统计/缓存/证书/日志：QPS 5-10

### 数据缓存
- 域名列表：缓存 5 分钟
- 统计数据：缓存 1 小时
- 证书列表：缓存 30 分钟

### 错误处理
- 统一错误码处理
- 友好的错误提示
- 失败重试机制

## 总结

**最推荐优先开发的功能：**

1. **域名管理** ⭐⭐⭐⭐⭐
   - 这是 CDN 管理的基础，用户需要先有域名才能使用其他功能
   - 实现难度：中等
   - 用户价值：极高

2. **用量统计** ⭐⭐⭐⭐
   - 用户关心流量消耗和费用
   - 实现难度：中等（需要图表库）
   - 用户价值：高

3. **域名配置** ⭐⭐⭐⭐
   - 提供精细化配置能力
   - 实现难度：较高（配置项多）
   - 用户价值：高

建议先实现域名管理的基础功能，让用户能够查看和管理域名，然后再逐步添加配置和统计功能。
